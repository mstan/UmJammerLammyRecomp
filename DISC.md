# Supported disc

Use your own US **Um Jammer Lammy (SCUS-94448)** disc image. Keep its CUE and
referenced BIN together, and extract ZIP/RAR archives before selecting the CUE.
The release includes no disc image or retail BIOS dump.

| Track 01 | Expected value |
| --- | --- |
| Format | MODE2/2352, one track |
| Size | 740,416,656 bytes |
| MD5 | `c5b047642aac6bd414dffce52909a940` |
| SHA-1 | `86fc942a25063c56bb21a20db14961b9f0ac0039` |
| CRC32 | `4775ad17` |

These identifiers were computed from the local supported dump. Other regions
and revisions have not been validated. A cooked 2048-byte ISO loses the XA
streaming sectors the game needs.

The launcher can use bundled OpenBIOS or your own supported retail BIOS. The
initial controller playtest used SCPH-1001. Personal settings, controller
bindings, saves, extracted resources and the resident cache stay on your PC.
